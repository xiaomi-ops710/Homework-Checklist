プッシュ通知の鍵（VAPID）を作る

このページは、いま開いている端末の中だけで鍵を作ります。鍵はどこにも送信されません。

大事：秘密の値（VAPID_PRIVATE）は、Renderの環境変数にだけ貼ってください。写真に撮ったり、メモに残したり、ほかの人に送ったりしないでください。

次にすること
  1. VAPID_PUBLIC を、GitHub の firebase-config.js の window.VAPID_PUBLIC_KEY = ""; の「 " 」の中に貼る
  2. VAPID_PUBLIC と VAPID_PRIVATE を、Render の環境変数に入れる
  3. 終わったら、このページを閉じる（鍵はこのページに残りません）
