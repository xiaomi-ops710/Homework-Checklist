# <img src="icon-192.png" width="40" align="top">  課題管理マネージャー

毎日の学習や考査（定期テスト）に向けた課題を効率的に管理し、モチベーションを高く維持するためのタスク管理Webアプリケーションです。直感的なUIと学習をサポートする多彩な機能を備えています。

## ✨ 主な機能

### 📝 タスク・課題管理
* **直感的な操作**: 課題の追加、編集、削除がスムーズに行えます。
* **ステータス管理**: 完了した課題には取り消し線が引かれ、ワンタップで未完了・完了の切り替えが可能です。
* **優先度と期日設定**: 考査の日程に合わせて、取り組むべき課題の優先順位を整理できます。また、設定しておくとテストまでの日数も表示されます。

### 📅 カレンダービュー
* **スケジュール把握**: 月間・週間カレンダー上で、どの日程にどの課題が設定されているかを視覚的に確認できます。
* **日付リンク**: カレンダーの日付を選択することで、その日のタスク一覧に素早くアクセスできます。

### ⏱️ フォーカスタイマー（集中モード）
* **ポモドーロ・テクニック対応**: 集中時間と休憩時間を交互に繰り返すタイマー機能を内蔵しています。
* **学習時間の記録**: タイマーで計測した学習時間は自動的に記録され、後から振り返ることができます。

### 📊 進捗の可視化
* **ダッシュボード**: 全体の課題消化率をドーナツチャートで分かりやすく表示します。
* **統計パネル**: 曜日ごとの学習時間や完了したタスクの推移を棒グラフで表示し、モチベーションの維持に貢献します。

### 🔥 Firebaseによるデータ自動クラウドバックアップ
* Googleアカウントでログインすることでクラウドバックアップ機能が有効になります。これにより、複数デバイスで進捗を共有することができ、データの損失を防ぎます。

## 🤖 AI機能（Powered by Gemini-3.5-flash-API)
アプリ全体にAI機能が組み込まれています。Googleアカウントにログインすることで使用できます。
* **わからないところをチャット**: 写真を添付したり、問題を提示することで分かりやすく説明します。
* **時間割**: 月〜土曜に対応。教科ごとの色で表示され、「あしたの時間割」と持ち物チェックリストをホームに表示します。
* **テスト対策プラン**: 考査の日までの勉強計画を、AIが日ごとに作り、カレンダーと「今日のやること」に入れます。
* **プリントの読み取り**: 課題に加えて、予定・テストの日程・持ち物も読み取って登録できます。
* **成績の推移**: 考査ごとの平均と、教科ごとの変化、目標との差を表示します。
* **きょうのおすすめ**: ホームに、今日やるとよいこと（単語帳の勉強・ノートの復習・持ち物など）を、状況に合わせてチップで提案します。
* **今日のやること**: ホームで、自分でやることを決めたり（時間の目安・毎日のくり返し）、AIに今日の計画を立ててもらったり、課題のノルマのページ数を調整したりできます。
* **まちがいノート**: 分からなかった問題と解き方をためて、1日・3日・1週間・2週間とあけながら復習します。5回できたら「卒業」。
* **AI小テスト**: 教科とテーマを決めると、AIが4択の問題と解説をつくります。
* **学習カレンダー**: 16週間の学習を、色の濃さで表示します。
* **AI先生（ツール）**: 分からない問題の写真を送ると、問題を読み取って解き方を教えてくれます。先生の名前・口調・教え方・学年・アイコンの色を自由に設定でき、「ヒントだけ」「似た問題を出して」など続けて質問できます。
* **アプリ全体に組み込まれたAI**: 例えば「単語帳」や「元素ラボ」など、ツール専用のAIも搭載しています。単語の覚え方や、理科の実験など、多角的から勉強をサポートします。
* **今日の勉強の進め方**: 課題や進捗状況に基づいて、今日は何を勉強すればいいかなど提案します。

## 📱 PWA（Progressive Web App）対応
* **アプリ化**: スマートフォンやタブレット（iOS/Android/iPadOS）の「ホーム画面に追加」機能により、ネイティブアプリのようにフルスクリーンで動作します。
* **オフライン対応**: キャッシュを利用し、ネットワーク環境が不安定な場所でも基本的なタスク確認が可能です。

## 🎨 UI / デザインの特徴
* **Material 3 Expressive**: 最新の Material 3 Expressive要素を全面的に採用。ユーザーの操作に対するフィードバックや、美しくなめらかなアニメーションを実装しています。
* **ダークモード完全対応**: OSの設定に連動、または手動切り替えで、目に優しいダークモードと視認性の高いライトモードをシームレスに切り替えます。
* **完全レスポンシブ設計**: スマートフォン、タブレット、PCなど、あらゆる画面サイズに対して最適なレイアウトに自動調整されます。
* **こだわりのタイポグラフィ**: 英語フォントに「Google Sans Flex」、日本語フォントに「Noto Sans JP」を採用。アイコンには「Material Symbols Rounded」を使用し、統一感のある洗練された外観を実現しました。

## 🛠️ 技術スタック

* **フロントエンド**: HTML5, CSS3, Vanilla JavaScript (フレームワーク非依存で軽量な動作を実現)
* **データ保存**: Web Storage API (LocalStorage) & Firebase Database（Googleアカウントログイン時のみ）
* **外部ライブラリ・アセット**:
  * フォント: Google Fonts
  * アイコン: Material Symbols
  * グラフ描画: Chart.js
